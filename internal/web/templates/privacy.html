A product feature, not fine print

Privacy

ProcessPilot uses a deliberately narrow view of your Mac. It does not upload your process history or machine telemetry.

Can see

What ProcessPilot can see

  • Process names and sanitized application identity
  • CPU and RAM usage
  • PID and parent-process relationships
  • Physical memory, available memory, and swap totals
  • System CPU and load averages
  • Sanitized, bounded historical versions of these measurements

Cannot see

What ProcessPilot cannot see

  • Passwords, credentials, API keys, or Keychain contents
  • Browser history, profiles, cookies, or databases
  • Emails, messages, documents, photos, or file contents
  • RAM contents or another process's memory
  • Keystrokes, clipboard contents, screen contents, or screenshots
  • Microphone, camera, contacts, calendar, or location
  • Network packet contents, DNS history, or HTTP request bodies

No elevated privileges. No remote dashboard. No automatic actions.

ProcessPilot does not require administrator privileges, Full Disk Access, Accessibility, Screen Recording, Input Monitoring, or Keychain access. The server binds to 127.0.0.1 by default, and ProcessPilot never automatically terminates processes.
